# Кейс 3. Генерация продуктовых гипотез

**Задача.** Владелец подписочного VPN-сервиса (мобильный клиент для Android, iOS и Huawei) передал дамп серверной БД, логи клиентов по инцидентам и структуру таблиц. Нужно сопоставить данные о клиентах и их действиях, сформулировать продуктовые гипотезы и подтвердить или опровергнуть каждую на данных. Каждая гипотеза оценивается отдельно.

**Результат.** Проверено 10 гипотез: 4 из условия и 6 собственных. Полное описание каждой (утверждение, данные, метод, результат, ограничения, вывод, рекомендация) — в отчёте `report/Practice_Synaptic_3.pdf`.

## Как воспроизвести

1. Открыть ноутбуки в Google Colab и запускать по порядку: `00` → `01` → `02` → `03` → `04` («Среда выполнения → Выполнить все»).
2. Ноутбук `00` сам скачивает данные по публичной ссылке владельца (Яндекс.Диск) на временный диск Colab и сохраняет обезличенные таблицы в Parquet на Google Drive (`MyDrive/case3/parquet`, 1–2 ГБ). Остальные ноутбуки работают с этим Parquet; `04` дополнительно скачивает `logs.zip`.
3. Время: `00` — 30–50 минут (скачивание около 9,5 ГБ), `01`–`03` — по несколько минут, `04` — 30–50 минут.
4. Результаты: текстовые сводки `*_results.txt` и графики `fig/*.png` в папке `MyDrive/case3`.

Инструменты: Python, DuckDB (SQL поверх Parquet), pandas, SciPy, matplotlib.

## Особенности данных

- В CSV нет строки заголовков: имена колонок берутся из `db_structure`.
- Поля без часового пояса в разных таблицах записаны по-разному (`users`, логи подключений и реклама — московское время; `orders`, `transactions`, `subscribe` — UTC); всё приведено к UTC.
- Объёма трафика в БД нет; потребление восстановлено по клиентским логам (80 пользователей, выборка смещена).
- 27.02.2026 подключения упали на 98 % на всех нодах — общий сбой; помесячные сравнения по подключениям не делаются.

## Персональные данные

При загрузке пароли, имена, токены, данные карт и ссылки на оплату удаляются; IP, идентификаторы устройств и внешних аккаунтов заменяются хешем с секретной солью. В репозиторий **не кладутся**: исходные данные, Parquet, файл соли `salt.txt`, промежуточные отчёты разведки.
